# 工程规范索引

本目录用于沉淀项目工程规范。执行代码开发、测试、配置、数据、接口或项目管理工作时，应遵守对应专题文档。

## 目录布局

- `开发规范`：项目结构、代码风格、配置运行时、日志、命令入口和 Git 管理。
- `接口与数据规范`：HTTP API、认证上下文、schema、响应、ORM、数据库和迁移。
- `质量规范`：测试组织、测试数据、fixture 和质量门禁。

## 文档索引

- [项目结构规范](./开发规范/项目结构规范.md)：目录职责、模块落位、分层边界和导入方向。
- [通用代码规范](./开发规范/通用代码规范.md)：代码风格、docstring、枚举、类型、异步资源、错误处理和日志调用。
- [配置与运行时规范](./开发规范/配置与运行时规范.md)：配置结构、配置加载、环境变量和应用启动边界。
- [日志规范](./开发规范/日志规范.md)：日志配置、输出格式、文件日志、请求日志和敏感信息边界。
- [项目指令规范](./开发规范/项目指令规范.md)：`app`、`make` 等项目命令入口和底层工具使用边界。
- [Git 项目管理规范](./开发规范/Git项目管理规范.md)：分支、原子提交和 Git 元数据相关项目管理流程。
- [API 设计规范](./接口与数据规范/API设计规范.md)：HTTP 路径、方法、参数、响应和错误边界。
- [认证与请求上下文规范](./接口与数据规范/认证与请求上下文规范.md)：用户登录态、session、当前用户解析和请求上下文。
- [数据结构与响应规范](./接口与数据规范/数据结构与响应规范.md)：schema、结构转换、响应包装、分页和 Pydantic 使用边界。
- [ORM 与数据模型规范](./接口与数据规范/ORM与数据模型规范.md)：ORM 模型、数据库 service、repository 绑定和持久化边界。
- [数据库与迁移规范](./接口与数据规范/数据库与迁移规范.md)：数据库迁移、数据修复和数据安全。
- [测试规范](./质量规范/测试规范.md)：测试目录结构、测试范围、fixture、测试数据和质量门禁。
