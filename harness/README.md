# 工程规范索引

本目录用于沉淀项目代码实现层面的所有约束规范。在执行代码开发、单元测试、工程配置调整等工作时，需要严格遵守本目录下的规范内容。

## 目录布局

- `开发规范`：约束项目结构、模块落位、通用代码风格和基础实现规则。
- `接口与数据规范`：约束 schema、请求响应、分页、数据库模型和 Pydantic 使用边界。
- `质量规范`：约束测试组织、测试数据、fixture 和质量门禁。

## 文档索引

- [项目结构规范](./开发规范/项目结构规范.md)：约束目录职责、代码模块落位、分层边界和导入方向。
- [通用代码规范](./开发规范/通用代码规范.md)：约束代码风格、类型、异步资源、错误处理和常用校验命令。
- [配置与运行时规范](./开发规范/配置与运行时规范.md)：约束配置结构、配置加载、环境变量和应用启动边界。
- [日志规范](./开发规范/日志规范.md)：约束日志配置、输出格式、文件日志、请求日志和敏感信息边界。
- [项目指令规范](./开发规范/项目指令规范.md)：约束 `app`、`make` 等项目命令入口和底层工具使用边界。
- [API 设计规范](./接口与数据规范/API设计规范.md)：约束 HTTP 路径、方法、参数、响应和错误边界。
- [认证与请求上下文规范](./接口与数据规范/认证与请求上下文规范.md)：约束用户登录态、Redis session、当前用户解析和请求上下文使用方式。
- [数据结构与响应规范](./接口与数据规范/数据结构与响应规范.md)：约束 `BaseStruct`、`CamelizedBaseStruct`、`GenericResponse`、`Pagination`、`CustomModel` 与 `pydantic.BaseModel` 的使用边界。
- [ORM 与数据模型规范](./接口与数据规范/ORM与数据模型规范.md)：约束 ORM 模型、服务、仓储绑定和数据对象转换规则。
- [数据库与迁移规范](./接口与数据规范/数据库与迁移规范.md)：约束数据库迁移和数据安全。
- [测试规范](./质量规范/测试规范.md)：约束测试目录结构、测试类型、fixture、测试数据和质量门禁。
