# 日志规范

本文档约束应用日志配置、日志输出和请求日志中间件。日志实现以 `LoggingConfig` 和 `LoggingSetup` 为入口。

## 配置入口

- 日志配置放在 `aigc.base.config.logging`。
- 日志配置通过 `Config.logging` 聚合。
- 日志结构继承 `BaseStruct`。
- 日志运行时适配放在 `aigc.shared.logging`。
- Litestar 日志配置和请求日志中间件由 `LoggingSetup` 创建。

## 输出格式

- 本地开发默认使用 `console`。
- 机器消费、生产采集或日志平台对接使用 `json`。
- 日志级别通过 `LoggingConfig.level` 控制。
- traceback 深度通过 `traceback_depth` 控制。
- 需要屏蔽第三方模块栈时使用 `suppress_modules`。

## 文件日志

- 文件日志默认关闭。
- 开启文件日志时，通过 `LoggingFileConfig` 配置路径、轮转策略和保留数量。
- 日志路径目录由日志适配层创建。
- 日志文件不得写入仓库。

## 请求日志

- 请求日志中间件由 server 层统一注册。
- 需要排除健康检查、文档或静态路径时，使用 `exclude_paths`。
- 不在 controller 或 service 中重复记录通用请求访问日志。

## 安全规则

- 日志不得输出密码、令牌、密钥、连接串和完整敏感配置。
- 异常日志不得展示局部变量中的敏感值。
- 业务日志使用结构化字段表达上下文，不拼接大段非结构化字符串。
